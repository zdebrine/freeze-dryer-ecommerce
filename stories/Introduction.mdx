# Coffee E-Commerce Component Library

Welcome to the Storybook for the Coffee E-Commerce platform. This component library contains all the UI components used throughout the application.

## Getting Started

To run Storybook locally:

```bash
npm run storybook
```

## Component Categories

### UI Components

Core UI components built with Radix UI primitives and styled with Tailwind CSS:

- **Button** - Versatile button with multiple variants and sizes
- **Card** - Container component for displaying content
- **Badge** - Status indicators and labels
- **Input** - Form input fields
- **And many more...**

### Shop Components

E-commerce specific components:

- **Product Grid** - Displays products in a responsive grid
- **Product Carousel** - Horizontal scrolling product display
- **Hero Section** - Landing page hero with video background
- **Testimonials** - Customer review display
- **Collection Boxes** - Category navigation cards

### Admin Components

Admin dashboard components:

- **Order Status Update** - Manage order workflow
- **Team Members Section** - Manage team and invitations
- **Weight Tracking** - Track freeze-drying weights and yields

## Design Tokens

The design system uses CSS custom properties defined in `globals.css`:

- **Colors**: Primary, secondary, destructive, muted, accent
- **Typography**: Font families, sizes, and weights
- **Spacing**: Consistent spacing scale
- **Border Radius**: Rounded corners

## Accessibility

All components are built with accessibility in mind:

- Proper ARIA attributes
- Keyboard navigation support
- Focus management
- Screen reader friendly
